# Mint Kernel For A30s

**For OneUI 3, AOSP Q/R/S**

## Features

* RKSU 3.0.0 (path_umount backported)
* WireGuard
* BBG
* EroFS
* USB Fast charge (upto 5000  mA)
* Power Suspend v2.0

### KernelSU vs Vanilla

**KernelSU**

* RKSU 3.0.0

**Vanilla**

* For Magisk & APatch

## Installation

Flash .zip in TWRP and reboot.
